## 📚 **Dissertation Insertion Guide**

### **Direct Insertion**:
1. **Insert → Picture → From File**
2. **Select**: Figure_X_*.png
3. **Size**: Use "Original Size" (don't resize)
4. **Position**: Center on page
5. **Caption**: Add figure caption below

### **No Cropping Required**:
- All figures have clean borders
- White backgrounds for printing
- Professional academic styling
- Optimal aspect ratios

### **LaTeX Integration**:
```latex
\begin{figure}[h!]
\centering
\includegraphics[width=0.9\textwidth]{Figure_1_Weather_Correlation_Matrix.png}
\caption{Weather variables correlation matrix showing multicollinearity patterns}
\label{fig:correlation}
\end{figure}
```
